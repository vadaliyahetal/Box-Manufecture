# Box Manufacturing Management System

A web-based Box Manufacturing Management System developed to simplify and manage daily manufacturing operations. The system helps manage customers, orders, production, inventory, payments, and overall business workflow efficiently.

## Features

- Customer Management
- Order Management
- Production Tracking
- Inventory Management
- Payment Management
- Sales & Purchase Records
- Dashboard & Business Overview
- Simple and User-Friendly Interface

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Purpose

The main purpose of this project is to digitize box manufacturing operations and reduce manual work by managing important business data in one centralized system.

## Database

The project uses **MySQL** for storing and managing customers, orders, products, inventory, production, and payment-related data.

## Project Type

Full Stack Web Application – Box Manufacturing Management System
